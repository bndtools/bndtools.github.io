## Bnd/Bndtools 7.5.0 Released

We are happy to announce the release of **Bnd/Bndtools 7.5.0**!

This release introduces significant improvements to Eclipse feature support, property conflict reporting, HTTP caching, and developer experience. Highlights include:

- **Eclipse Features on Build Paths** — support for referencing Eclipse features in `-buildpath`, `-testpath`, `-runpath`, and `-runbundles` with automatic expansion to member bundles
- **Property Conflict Detection** — new `-propertyconflicts` property for detecting and reporting duplicate property definitions with detailed diagnostics
- **Conditional Import Resolution** — added support for `resolution:=conditional` on Import-Package for better control over optional dependencies
- **HTTP Cache Improvements** — negative caching for 404 responses to reduce unnecessary network requests
- **Javac Release Option Support** — new `javac.release` property for using `javac --release` flag to prevent accidental use of newer platform APIs
- **Trusted Checksums: strict-jar-only Policy** — new policy focusing on jar file checksums to improve Eclipse integration
- **Optimized Rebuild Trigger Policy** — faster Eclipse rebuilds by preserving JAR timestamps when rebuilds produce identical artifacts
- **JAR Lifecycle Listeners** — new plugin interface for artifact signing, metadata generation, and validation
- **P2 Repository Enhancements** — explicit index filenames, cache link collision prevention, and improved namespace handling
- **Bndtools UI Improvements** — support for Eclipse features in Build Path and Run Bundles panes with canonical clause generation

For the full list of changes, see the [**Release Notes for 7.5.0**](https://github.com/bndtools/bnd/wiki/Changes-in-7.5.0).
